Dimenzió

A gemini-embedding kimenete.

A szövegeket sűrű vektorrá alakítjuk. A Qdrant koszinusz-hasonlóság alapján találja meg a releváns múltbéli válaszokat a felhőben.

Megvalósítás (1/4): Hitelesítés és Vektorizálás

  • Aszinkron API: A végpont fogadja a requestet, és szigorúan ellenőrzi az aktuális business_id jogosultságot.
  • Azonnali Embedding: Az ügyfél értékelését a Google API vektorizálja a kereséshez.

Megvalósítás (2/4): Multi-tenant Keresés

  • Payload Filtering: A keresést egy FieldCondition kizárólag a lekérdező cég adataira korlátozza.
  • O(1) Adatbiztonság: A Qdrant a hash-alapú szűrést a matematikai vektorkeresés előtt hajtja végre (Nincs átszivárgás).

Megvalósítás (3/4): Biztonsági Architektúra

  • XSS Védelem (HttpOnly): A tokeneket nem a sebezhető localStorage-ban, hanem HttpOnly és Secure flagekkel ellátott sütikben tároljuk.
  • Állapotmentes JWT: Minden API hívásnál a backend middleware fejti vissza a tokent, kizárva az illetéktelen (IDOR) hozzáférést.

Megvalósítás (4/4): Prompt & Generálás

  • Dinamikus Injekció: A cég stílusirányelve és a visszakapott példák beoltása a System Prompt-ba.
  • Agentic LLM Hívás: A Gemini 2.5 Flash a tényadatok alapján hallucinációmentes választervezetet ír.
  • Perzisztencia: Az eredmény mentődik a PostgreSQL adatbázisba.

Mérnöki kihívások és megoldások

  • Docker Driver konfliktus: PCI/Chipset driver ütközések a WSL2 rétegben → Megoldás: Managed Qdrant Cloud.
  • Változó API környezet: A Qdrant v1.16+ verzióváltás miatt eltűnt a .search() → Megoldás: Migráció az új query_points() API-ra.
  • Google API Quota (Quota 0): Korlátozott API hozzáférés nem hitelesített appként → Megoldás: Robusztus ETL pipeline fejlesztése szimulált adatokhoz a vektortér feltöltésére.
  • Render.com Deployment: Port-scanner timeout hibák → Megoldás: Explicit 10000-es port binding és Build Cache törlés.
